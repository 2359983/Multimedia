# ESV3
[TP3](tp3audio.mp4)
Pour réaliser mon ESV3, j'ai choisi une image représentant une jungle sur le site Pixabay. À partir de cette image, j'ai créé une ambiance sonore en ajoutant différents effets audio pour représenter les bruits qu'on pourrait entendre dans cet environnement. J'ai utilisé plusieurs sons, comme des bruits de pas dans les feuilles, des oiseaux, de la pluie, des battements d'ailes, des cris d'animaux, le bruit d'une rivière et des singes. J'ai ensuite combiné les différents sons afin de créer une ambiance réaliste et de donner l'impression d'être dans une jungle. Ce travail m'a permis de découvrir comment le son peut rendre une image plus vivante et créer une atmosphèr
